# 任务卡：用户服务

| 项 | 内容 |
|---|---|
| 模块 | `services/doinb-user`（端口 **8082**） |
| 负责人 | （填写） |
| 用例 | UC-01 注册、UC-02 登录/登出、UC-03 资料 |
| 测试模块 | M1 |
| 从哪拷 | `UserAccountController` `UserController` `UserAccountServiceImpl` `UserServiceImpl` `UserDetailsServiceImpl` `UserMapper` |

## 功能

注册、登录、管理员登录、登出、改密码、查/改资料、上传头像、公开展示页。登录成功签发 JWT（`JwtUtil.createToken(userId, "user"|"admin")`），密钥与网关相同。

## 库表（只动这些）

| 表 | schema（目标） | 文件 |
|---|---|---|
| `users` | `doinb_user` | 头像文件归本服务，URL 形如 `/uploads/avatars/...` |

其它服务只存 `user_id`，要昵称走内部接口。

## 对外接口（路径禁止改）

`POST /user/account/register` `POST /user/account/login` `POST /admin/account/login`  
`GET /user/account/logout` `GET /user/personal/info` `GET /admin/personal/info`  
`POST /user/password/update` `GET /user/info/get-one` `GET /user/profile/showcase`  
`POST /user/info/update` `POST /user/avatar/upload`  
`GET /health`（骨架已有）

公开（可无 token，网关已放行）：注册、两种登录、`get-one`、`showcase`、头像静态文件。

`/user/profile/showcase` 本期只返回资料（`videos` 空、`following=false`）。作品列表归视频服务，关注状态归互动服务，切流后由它们补，本服务不查 `videos` 表。

当前用户用 `GatewayUser.requireUserId(request)`，不要再用单体里的 `CurrentUser`（那套依赖 Security 查库）。

## 你提供给别人（必须实现，桩已在 `internal/`）

| 调用方 | 方法 | 路径 |
|---|---|---|
| 互动 / 他人拼昵称 | GET | `/internal/users/{id}` |
| 视频、直播、互动、消息 | GET | `/internal/users?ids=1,2,3` |
| 网关搜索 | GET | `/internal/search/users?keyword=&limit=` |

头：`X-Internal-Token`。`data` 用 `com.doinb.common.dto.UserDTO`。

## 你要调用谁

**无。** 不要调其它业务服务。

## 通信方式

- 浏览器 → 网关 → 本服务：同步 HTTP
- 其它服务 → 本服务内部接口：同步 HTTP + `X-Internal-Token`

## 验收

- 单体里 U000～U081 对应接口行为不变（`code/message`）
- 登录返回的 token，网关能解析并注入 `X-User-Id`
- 三个内部接口有真实数据，网关 `GET /search?keyword=` 能出用户
- 不碰 `videos` / `comments` 等表
