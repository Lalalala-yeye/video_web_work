# 任务卡：互动服务

| 项 | 内容 |
|---|---|
| 模块 | `services/doinb-interact`（端口 **8085**） |
| 负责人 | （填写） |
| 用例 | UC-09 关注与订阅动态、UC-10 评论、UC-11 赞踩 |
| 测试模块 | M3、M4、M5 |
| 从哪拷 | `CommentController` `ReactionController` `SubscriptionController` 及三个 `*ServiceImpl` |

## 功能

视频评论与直播弹幕、视频/评论赞踩、关注/取关、关注列表、订阅动态。跨服务调用最多，先把内部调用写对再补业务细节。

## 库表（只动这些）

| 表 | schema（目标） |
|---|---|
| `comments` | `doinb_interact` |
| `comment_reactions` | `doinb_interact` |
| `video_reactions` | `doinb_interact` |
| `subscriptions` | `doinb_interact` |

`target_id` / `video_id` / `follower_id` 只存对方 ID。**禁止** 再注入 `VideoMapper` `LiveRoomMapper` `UserMapper`。

## 对外接口（路径禁止改）

`POST /comment/add` `GET /comment/list`  
`GET /video/reaction/summary` `POST /video/reaction` `POST /comment/reaction`  
`POST /subscription/follow` `POST /subscription/unfollow`  
`GET /subscription/status` `GET /subscription/following` `GET /subscription/feed`

公开：`comment/list`、`video/reaction/summary`。  
`/video/reaction/**` 由网关从 `/video` 里拆出来打到你这里。

当前用户：`GatewayUser.requireUserId(request)`。

## 你提供给别人

本期 **无** 内部接口。消息服务创建通知时请调用方带上 `preview` 和 `linkPath`，不要反过来查你的评论。

## 你要调用谁（必须按契约）

| 何时 | 目标 | 方式 |
|---|---|---|
| 评视频 | 视频 `GET /internal/videos/{id}` | 同步 HTTP；404 → 「视频不存在」 |
| 发弹幕 / 拉本场弹幕 | 直播 `GET /internal/lives/{id}` | 同步 HTTP；无房间 404；未开播发弹幕 400 |
| 关注 | 用户 `GET /internal/users/{id}` | 同步 HTTP；404 → 「目标用户不存在」 |
| 关注列表 / 动态拼昵称 | 用户 `GET /internal/users?ids=` | 同步 HTTP |
| 订阅动态 | 视频 `GET /internal/videos/by-authors?authorIds=&limit=100` | 同步 HTTP |
| 订阅动态 | 直播 `GET /internal/lives/by-anchors?anchorIds=&limit=50` | 同步 HTTP |
| 点赞视频/评论 | 消息 `POST /internal/notifications` | 同步 HTTP，type=1 或 2，带 linkPath |

注入已有的 `ServiceClient` 和 `DoinbProperties.getServices()`。

```java
CustomResponse video = serviceClient.get(
    properties.getServices().getVideo(),
    InternalPaths.VIDEOS + "/" + targetId);
if (video.getCode() == 404) {
    return CustomResponse.fail(404, "视频不存在");
}
```

## 通信方式

全部同步 HTTP + JSON。不要上 MQ。

## 验收

- C000～C010、R000～R010、F000～F030 行为与单体一致
- 未开播发弹幕仍是 400
- 点赞会打到消息服务内部接口（可用日志/桩响应确认）
- 本服务进程里没有其它服务的 Mapper
