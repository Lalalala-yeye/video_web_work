# 任务卡：视频服务

| 项 | 内容 |
|---|---|
| 模块 | `services/doinb-video`（端口 **8083**） |
| 负责人 | （填写） |
| 用例 | UC-04 浏览播放、UC-05 历史、UC-06 上传编辑、UC-07 举报、UC-15 审核 |
| 测试模块 | M2、M10 |
| 从哪拷 | `VideoController` `AdminVideoController` `VideoServiceImpl` `AdminVideoServiceImpl` 及对应 Mapper |

## 功能

列表/详情、播放进度与历史、上传/改/可见性/删除、举报；管理端待审、通过、驳回、举报复审、删除。封面与视频文件归本服务（`/uploads/covers/`、`/uploads/videos/`）。

## 库表（只动这些）

| 表 | schema（目标） |
|---|---|
| `videos` | `doinb_video` |
| `play_history` | `doinb_video` |
| `video_reports` | `doinb_video` |

`author_id` 只存数字，昵称用用户内部接口。审核通过 **不要** 再注入 `NotificationService`。

## 对外接口（路径禁止改）

`GET /video/list` `GET /video/getone`  
`POST /video/history/progress` `GET /video/history/list`  
`POST /video/upload` `GET /video/my/list` `GET /video/my/getone`  
`POST /video/update` `POST /video/visibility` `POST /video/delete` `POST /video/report`  
`GET /admin/video/pending` `GET /admin/video/getone`  
`POST /admin/video/approve` `POST /admin/video/reject`  
`GET /admin/video/report-review` `GET /admin/video/reports` `POST /admin/video/delete`

注意：`/video/reaction/**` 归 **互动服务**，网关已按更长前缀转发，你不要实现赞踩。

管理员接口：`GatewayUser.isAdmin(request)` 为假则 403。

## 你提供给别人（桩在 `internal/`）

| 调用方 | 方法 | 路径 |
|---|---|---|
| 互动（评论前） | GET | `/internal/videos/{id}` |
| 互动（订阅动态） | GET | `/internal/videos/by-authors?authorIds=&limit=` 仅已发布 |
| 网关搜索 | GET | `/internal/search/videos?keyword=&limit=` 仅已发布 |

## 你要调用谁

| 何时 | 目标 | 方式 |
|---|---|---|
| 审核通过 | 消息 `POST /internal/notifications` | 同步 HTTP，`ServiceClient.post`，type=4，带 `linkPath=/video/{id}` |
| 列表拼作者昵称（可选） | 用户 `GET /internal/users?ids=` | 同步 HTTP；先做本地桩也可先显示「未知作者」 |

```java
CreateNotificationRequest n = new CreateNotificationRequest();
n.setUserId(authorId);
n.setType(4);
n.setActorId(adminId);
n.setRefId(videoId);
n.setPreview("你的视频《" + title + "》已通过审核并公开发布");
n.setLinkPath("/video/" + videoId);
serviceClient.post(properties.getServices().getMessage(), InternalPaths.NOTIFICATIONS, n);
```

## 通信方式

同步 HTTP。上传走网关转发，超时已放宽到 10 分钟。

## 验收

- V000～V063、A000～A040 行为与单体一致
- 通过审核后消息服务能收到内部通知请求
- 互动调 `/internal/videos/{id}` 能区分存在/不存在
- 不写 `comments` `notifications` `users`
