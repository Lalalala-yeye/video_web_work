## 一、用例判定口径

按《软件工程基础实践》任务书定义：一个业务场景（用例）指由一类用户或外部系统触发、为完成一个明确业务目标、从开始到产生可验证结果的一段完整流程。单个页面、按钮、接口或流程中的一步不单独算用例。每个用例包含主成功流程、备选流程和异常流程，作为同一用例的不同路径。

## 二、参与者定义

| 参与者 | 说明 |
|---|---|
| 访客 | 未注册/未登录的用户，仅能进入注册、登录页面 |
| 注册用户 | 完成登录的普通用户（role=0），可观看、互动、私信、搜索 |
| 作者 | 具备内容发布权限的注册用户（role=1），在注册用户能力之上可上传视频、管理直播间 |
| 管理员 | 平台管理角色（role=2），负责视频审核、举报复审、内容管理 |

## 四、用例说明（六要素）

### UC01 用户注册与登录

| 要素 | 内容 |
|---|---|
| 参与者 | 访客、注册用户 |
| 触发条件 | 访客在登录页点击"立即注册"提交注册信息；或用户在登录页提交账号密码 |
| 前置条件 | 系统正常运行；注册时用户名未被占用 |
| 主成功流程 | 1) 访客填写用户名、密码、昵称提交注册，服务端完成唯一性与格式校验后写入用户数据并提示成功；2) 用户输入账号密码登录，服务端校验通过后签发 JWT 令牌，前端保存令牌进入已登录态，按角色展示功能入口；3) 用户可在个人中心查看/修改资料与头像，可修改密码；4) 用户可退出登录使令牌失效，支持本地多账号切换 |
| 备选/异常流程 | 用户名已存在→提示注册冲突；账号或密码错误→给出明确失败提示（不泄露具体是哪项错误）；未登录调用需鉴权接口→返回 401 引导登录；令牌过期→跳转登录页重新登录 |
| 可验证结果 | 新注册账号可成功登录；users 表新增记录；异常场景均有明确提示；对应测试编号 UNIT-TC01~、INT-TC01、E2E-TC01 |

### UC02 视频上传与审核发布

| 要素 | 内容 |
|---|---|
| 参与者 | 作者、管理员 |
| 触发条件 | 作者在创作中心上传页提交视频；或管理员进入后台待审列表 |
| 前置条件 | 作者已登录且具备发布权限；视频文件不超过 500MB 且格式符合要求 |
| 主成功流程 | 1) 作者选择视频文件与封面，填写标题、简介、可见性后提交；2) 服务端校验通过后将文件保存至服务器存储目录，并写入视频元数据（状态=待审核）；3) 管理员在后台待审列表中预览视频内容；4) 管理员审核通过，视频状态变为已发布，在公开列表可见；5) 系统向作者推送审核结果通知 |
| 备选/异常流程 | 文件超限或格式不符→提交被拒绝并给出原因；管理员驳回→视频转为仅作者可见并通知作者；作者可将视频设为仅自己可见、编辑信息或删除稿件；未授权账号调用上传接口→401/403 |
| 可验证结果 | 审核通过后视频出现在公开列表且可播放；驳回后仅作者可见；notifications 表产生审核结果记录；对应测试编号 INT-TC02、E2E-TC02 |

### UC03 视频浏览与播放

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户 |
| 触发条件 | 用户打开首页或从搜索/订阅动态进入视频详情页并发起播放 |
| 前置条件 | 已登录；目标视频状态为已发布（或为本人视频） |
| 主成功流程 | 1) 用户打开首页，系统返回视频列表（封面、标题、作者等）；2) 点击进入视频详情页，加载视频元数据与播放地址；3) 播放器在线播放，支持暂停、进度调节；4) 播放行为触发播放历史写入/更新，记录观看进度；5) 用户可在历史页查看播放记录并从上次进度续播 |
| 备选/异常流程 | 视频不存在或已下架→提示无法播放；列表或历史无数据→展示空状态；网络或加载异常→给出可理解的错误提示，不影响其他功能 |
| 可验证结果 | 完整播放一次视频后，play_history 表存在记录且历史页可见、进度正确；对应测试编号 E2E-TC03 |

### UC04 评论与赞踩

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户（评论者/点赞者）、作者（被互动方） |
| 触发条件 | 用户在视频详情页提交评论，或点击视频/评论的赞、踩按钮 |
| 前置条件 | 已登录；目标视频或评论存在 |
| 主成功流程 | 1) 用户输入文字或选择表情图片提交评论，写入评论数据后评论列表刷新展示；2) 用户对视频点赞/点踩，系统记录该用户对视频的反应状态并更新计数汇总；3) 用户对某条评论点赞/点踩，同样记录状态并更新计数；4) 被互动的作者收到系统通知 |
| 备选/异常流程 | 未登录→提示登录后再操作；评论内容为空→拒绝提交；用户再次点击赞/踩→切换或取消该反应，计数同步更新；目标已被删除→提示不存在 |
| 可验证结果 | 新评论即时出现在评论列表；本人赞踩状态与计数显示正确；被互动方通知面板出现记录；对应测试编号 INT-TC04、E2E-TC04 |

### UC05 关注与订阅动态

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户（关注者）、作者（被关注者） |
| 触发条件 | 用户在他人公开主页或视频页点击"关注"按钮 |
| 前置条件 | 已登录；目标用户存在 |
| 主成功流程 | 1) 用户点击关注，系统写入订阅关系，按钮状态变为已关注；2) 用户打开订阅动态页，系统按关注列表聚合展示被关注作者的最新视频并分页；3) 用户可取消关注，系统删除订阅关系并刷新状态 |
| 备选/异常流程 | 目标用户不存在→提示失败；并发重复点击关注/取消→以最终一致状态为准，避免重复提示 |
| 可验证结果 | 关注某作者后，其新视频出现在订阅动态页；取消后不再出现；subscriptions 表状态正确；对应测试编号 INT-TC05、E2E-TC05 |

### UC06 私信与通知

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户（发送方/接收方） |
| 触发条件 | 用户在他人公开主页点击私信图标发起会话；或他人互动/系统事件产生通知 |
| 前置条件 | 双方均已注册登录；接收方账号存在 |
| 主成功流程 | 1) 发送方进入与对方的私信房间（无则自动创建）；2) 发送消息，写入私信数据并在会话中展示；3) 接收方在通知面板看到未读提醒，进入会话查看并回复；4) 用户在通知面板查看未读数、逐条标记已读（通知类型含点赞、私信、审核结果等） |
| 备选/异常流程 | 未登录→401 引导登录；消息内容为空→拒绝发送；对方账号不存在→提示失败 |
| 可验证结果 | 双方在同一会话中能看到彼此消息往返；未读数随已读操作减少为 0；对应测试编号 INT-TC06、E2E-TC06 |

### UC07 关键词搜索

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户 |
| 触发条件 | 用户在顶部导航搜索框输入关键词并提交 |
| 前置条件 | 已登录；关键词非空 |
| 主成功流程 | 1) 用户输入关键词发起搜索；2) 服务端在视频标题、用户昵称等字段执行模糊匹配查询；3) 返回视频结果与用户结果并分页展示；4) 用户点击结果跳转视频详情页或用户公开主页 |
| 备选/异常流程 | 关键词为空或含非法字符→提示并阻止；无匹配结果→展示空结果页；查询超时→提示重试 |
| 可验证结果 | 按已发布视频的标题关键词能搜到该视频并成功跳转详情页；对应测试编号 INT-TC07、E2E-TC07 |

### UC08 直播间管理

| 要素 | 内容 |
|---|---|
| 参与者 | 作者（主播）、注册用户（观众） |
| 触发条件 | 作者在创作中心创建直播间并开播；观众打开直播列表 |
| 前置条件 | 作者已登录；直播间标题等信息填写完整 |
| 主成功流程 | 1) 作者创建直播间，系统写入直播间数据（初始为未开播）；2) 作者执行开播，直播间状态变为直播中；3) 观众在直播列表查看进行中的直播间并进入直播间页，查看房间信息并发表直播评论；4) 作者停播后房间状态更新，系统定时任务维护直播间状态一致性 |
| 备选/异常流程 | 直播间不存在或已结束→进入时明确提示；直播画面依赖外部推流工具与 SRS 流媒体服务，观众端画面在本版本为演示占位（不计入验收，见第六节说明）；未开播状态下观众进入→按实际设计提示 |
| 可验证结果 | 直播间创建/开播/停播的状态流转正确并体现在列表；直播评论即时可见；对应测试编号 INT-TC08、E2E-TC08 |

### UC09 举报与管理员复审

| 要素 | 内容 |
|---|---|
| 参与者 | 注册用户（举报人）、管理员 |
| 触发条件 | 用户在视频详情页点击举报提交；或管理员进入后台举报复审页 |
| 前置条件 | 举报人已登录且目标视频存在；管理员为 role=2 |
| 主成功流程 | 1) 用户对违规视频提交举报，系统写入举报记录；2) 管理员在后台查看举报列表，预览被举报视频；3) 管理员复审处置：驳回举报（视频维持现状）或对视频执行删除/下架；4) 举报与处置记录留存可查 |
| 备选/异常流程 | 目标视频已被删除→提示无法举报；非管理员访问复审接口→403；举报信息不完整→拒绝提交 |
| 可验证结果 | 举报后 video_reports 表新增记录；管理员处置后视频可见状态与处置一致；对应测试编号 INT-TC09、E2E-TC09 |
