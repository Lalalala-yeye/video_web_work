# 部署文档

## 1 引言

### 1.1 编写目的

本文档旨在指导项目团队在本地开发环境或服务器环境中部署 “doinb 视频播放与内容服务平台”，确保系统能够稳定运行，并为后续测试、演示和维护提供依据。

### 1.2 定义

API：应用程序编程接口。

JWT：JSON Web Token，用于用户身份认证。

Vite：前端开发和构建工具。

SRS：Simple Realtime Server，可用于本项目直播推流和拉流演示。

Nginx：Web 服务器和反向代理服务器。

### 1.3 预期读者

本文档的预期读者包括项目开发人员、测试人员、系统管理员和任何需要了解系统部署过程的相关人员。

## 2 系统部署要求

### 2.1 硬件要求

服务器：建议 2 核 CPU，4GB 内存，20GB 以上存储空间。若需要保存较多视频文件，应根据上传文件数量扩展磁盘空间。

操作系统：Windows 10/11、Windows Server 2019 或主流 Linux 发行版。

数据库：MySQL 8.0。

网络：局域网或互联网连接，前端、后端、数据库和直播媒体服务之间可以互相访问。

### 2.2 软件要求

操作系统：Windows 或 Linux。

数据库：MySQL 8.0。

后端运行环境：JDK 25。

后端框架：Spring Boot 4.1.0-SNAPSHOT、Spring Security、MyBatis-Plus、MySQL Connector/J、JWT。

前端运行环境：Node.js 20.19+ 或 22.12+，npm。

前端框架：Vue 3、Vite、Vue Router、Element Plus、Axios。

可选软件：Docker、SRS、Nginx。

数据库服务器：

### 3.3 应用服务器部署

#### 3.3.1 部署描述

部署前端 Vue 程序，执行以下步骤：

安装 Node.js 和 npm。

克隆或复制项目代码库。

进入前端目录：

```powershell
cd web
```

安装依赖项：

```powershell
npm install
```

开发环境启动前端：

```powershell
npm run dev
```

项目打包：

```powershell
npm run build
```

将生成的 `dist` 文件夹部署到 Nginx 或其他静态 Web 服务目录。

部署后端 Spring Boot 项目，执行以下步骤：

克隆或复制项目代码库。

进入后端目录：

```powershell
cd backend
```

配置本地配置文件，将模板复制为本地配置：

```powershell
copy src\main\resources\application-local.example.yml src\main\resources\application-local.yml
```

修改 `application-local.yml` 中的数据库账号、密码和 JWT 密钥。

开发环境启动后端：

```powershell
.\mvnw.cmd spring-boot:run
```

生产或演示环境打包：

```powershell
.\mvnw.cmd clean package -DskipTests
```

将生成的 jar 包上传到服务器后执行：

```bash
nohup java -jar backend-0.0.1-SNAPSHOT.jar &
```

#### 3.3.2 系统软件

Web 服务器：Nginx 或 Vite 开发服务器。

应用服务器：Spring Boot 内置 Web 容器。

数据库服务器：MySQL 8.0。

直播媒体服务：SRS（可选，用于真实推流/拉流演示）。

#### 3.3.3 系统软件配置

后端默认配置文件为：

```text
backend/src/main/resources/application.yml
```

关键配置如下：

```yaml
server:
  port: 8081

spring:
  profiles:
    active: local
  servlet:
    multipart:
      max-file-size: 500MB
      max-request-size: 500MB

upload:
  path: uploads
```

本地私有配置文件为：

```text
backend/src/main/resources/application-local.yml
```

示例配置如下：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/doinb?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: "你的MySQL密码"

jwt:
  secret: "至少32个字符的随机字符串"
```

前端开发服务器配置文件为：

```text
web/vite.config.js
```

当前端口和代理配置如下：

```js
server: {
  host: true,
  port: 8787,
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:8081',
      changeOrigin: true,
      rewrite: (p) => p.replace(/^\/api/, '')
    }
  }
}
```

Nginx 配置示例：

```nginx
server {
    listen 80;
    server_name 你的服务器IP或域名;

    location / {
        root /root/doinb/dist;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8081/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /uploads/ {
        alias /root/doinb/uploads/;
    }
}
```

### 3.4 MySQL 数据库服务器部署

#### 3.4.1 部署描述

要部署 MySQL 数据库服务器，执行以下步骤：

安装 MySQL 8.0。

创建数据库：

```sql
CREATE DATABASE doinb DEFAULT CHARACTER SET utf8mb4;
```

进入 `doinb` 数据库，执行项目数据库脚本：

```text
database/database.sql
```

确认创建以下主要数据表：

`users`：用户表。

`videos`：视频表。

`live_rooms`：直播间表。

`subscriptions`：关注订阅表。

`comments`：评论表。

`play_history`：播放历史表。

`video_reactions`：视频赞踩表。

`comment_reactions`：评论赞踩表。

`notifications`：通知表。

`dm_rooms`：私信房间表。

`dm_messages`：私信消息表。

`video_reports`：视频举报表。

#### 3.4.2 系统软件

数据库管理工具：Navicat、DataGrip、MySQL Workbench 或命令行工具。

数据库版本：MySQL 8.0。

#### 3.4.3 系统软件配置

数据库名：doinb

用户名：占位

用户密码：占位

字符集：utf8mb4

时区：Asia/Shanghai

如果需要设置管理员账号，可在注册普通用户后执行：

```sql
UPDATE users SET role = 2 WHERE username = '管理员用户名';
```

### 3.5 直播服务部署

若只演示直播房间状态和直播评论，可以不启动 SRS。若需要 OBS 推流和浏览器播放 HLS/FLV，则需要部署 SRS。

本项目提供本地 Docker 启动脚本：

```powershell
.\deploy\srs-docker.ps1
```

SRS 默认端口：

RTMP 推流端口：1935

HLS/FLV 播放端口：8080

SRS API 端口：1985

WebRTC 端口：8000

OBS 推流地址示例：

```text
rtmp://服务器IP/live/{streamKey}
```

HLS 播放地址示例：

```text
http://服务器IP:8080/live/{streamKey}.m3u8
```

当前后端使用 8081 端口，是为了避免和 SRS 的 8080 端口冲突。

### 3.6 防火墙与端口

本项目默认端口如下：

| 服务 | 端口 | 协议 | 说明 |
| --- | --- | --- | --- |
| 前端 Vite | 8787 | TCP | 前端开发服务器 |
| 后端 API | 8081 | TCP | Spring Boot REST API |
| SRS HLS/FLV | 8080 | TCP | 直播播放 |
| SRS RTMP | 1935 | TCP | OBS 推流 |
| SRS API | 1985 | TCP | SRS 管理接口 |
| SRS WebRTC | 8000 | TCP/UDP | WebRTC 直播 |
| MySQL | 3306 | TCP | 数据库连接 |

Windows 本地演示需要放行端口时，可以使用管理员 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\firewall-doinb.ps1 -Action add
```

删除规则时执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\firewall-doinb.ps1 -Action remove
```

### 3.7 部署验证

后端启动后访问健康检查接口：

```text
http://localhost:8081/health
```

期望返回：

```json
{
  "code": 200,
  "message": "OK",
  "data": "doinb-backend ok"
}
```

前端启动后访问：

```text
http://localhost:8787
```

验证首页能够打开，注册登录能够正常使用。

执行以下功能验证：

注册一个普通账号并登录。

上传一个测试视频并在创作中心查看。

将账号设置为管理员，进入 `/admin/pending` 审核视频。

审核通过后回到首页，确认视频出现在公开视频列表。

进入视频详情页，播放视频并发表评论。

关注视频作者，在订阅页查看动态。

创建直播间并开播，确认直播列表出现该房间。

## 4 注意事项

`application-local.yml` 中包含数据库密码和 JWT 密钥，不应提交到公开仓库。

数据库密码中含有 `@`、`:`、`#` 等特殊字符时，应使用英文双引号包裹。

开发环境前端代理路径为 `/api`，会转发到后端 `8081` 端口；如果修改后端端口，应同步修改 `web/vite.config.js`。

上传文件默认保存在项目运行目录下的 `uploads` 文件夹。部署到服务器时，应保证该目录存在并具有写入权限。

生产环境建议使用 Nginx 提供前端静态文件和上传资源访问，不建议直接使用 Vite 开发服务器。

MySQL 数据库建议定期备份，避免误删用户、视频和评论数据。

如果需要手机或局域网设备访问，应使用电脑局域网 IP 打开前端地址，并放行 8787、8081、8080、1935、8000 等端口。

直播真实推流依赖 SRS、OBS 或其他流媒体服务；仅启动前后端时，直播房间状态和评论可用，但不一定有真实直播画面。
