# 测试报告

## 1 引言

### 1.1 目标

本测试报告旨在描述对 “doinb 视频播放与内容服务平台” 系统的测试活动，包括测试范围、测试方法、测试环境、测试用例和测试结果，确保系统在提交前经过较完整的功能验证，达到课程项目预期的功能和稳定性要求。

### 1.2 背景

“doinb 视频播放与内容服务平台” 是一个基于 Spring Boot 后端与 Vue 3 前端的视频内容网站，提供用户注册登录、视频浏览播放、视频上传与编辑、评论互动、关注订阅、搜索、通知私信、直播房间管理与管理员审核等功能。为了保证系统功能完整、页面流程顺畅、数据读写正确，需要对各功能模块进行系统性测试。

### 1.3 范围

本测试报告适用于 “doinb 视频播放与内容服务平台” 的主要模块，包括用户与权限管理、视频播放、视频发布与编辑、评论与赞踩、关注订阅、搜索、通知私信、直播房间和管理员审核功能。测试范围以功能测试、接口联调测试、页面流程测试和常见异常测试为主。

## 2 测试计划

### 2.1 目的

测试活动的目的在于验证 “doinb 视频播放与内容服务平台” 是否满足需求规格说明书和设计说明书中的功能要求。测试活动包括准备测试环境、设计测试用例、执行测试、记录测试日志和总结测试结果。

### 2.2 详细说明

#### 2.2.1 测试计划标识符

测试计划编号：Doinb2026-TP-001

#### 2.2.2 引言

“doinb 视频播放与内容服务平台” 由前端页面、后端接口、数据库和本地上传资源目录组成。测试将围绕用户可见的操作流程展开，覆盖从注册登录、观看视频、上传视频、互动评论到管理员审核的完整链路。

#### 2.2.3 测试项

测试项包括：

用户与权限管理模块（版本 1.0）

视频浏览与播放模块（版本 1.0）

视频发布与编辑模块（版本 1.0）

评论、赞踩与分享模块（版本 1.0）

关注订阅与订阅动态模块（版本 1.0）

搜索模块（版本 1.0）

通知与私信模块（版本 1.0）

直播房间模块（版本 1.0）

管理员审核与举报复审模块（版本 1.0）

#### 2.2.4 要测试的特征

用户登录注册功能：用户注册、登录、退出、个人资料修改、头像上传、多账号切换。

视频播放功能：首页视频列表、视频详情、播放器加载、播放历史记录与进度保存。

视频发布功能：视频上传、封面上传、标题简介填写、视频编辑、可见性修改、删除稿件。

互动功能：视频评论、直播评论、视频赞踩、评论赞踩、复制分享链接。

关注订阅功能：关注作者、取消关注、查看关注状态、订阅动态列表。

搜索功能：按关键词搜索视频、直播间和用户。

消息功能：通知列表、未读数量、通知已读、私信房间打开和消息发送。

直播功能：创建直播间、开播、停播、直播列表展示、进入直播间、直播评论。

管理功能：管理员登录、待审视频列表、视频审核通过、视频驳回、视频举报复审、管理员删除视频。

#### 2.2.5 不要测试的特征

本次测试不覆盖真实商业级高并发压测、不覆盖完整 AI 审核与以图搜视频功能、不覆盖真实线上支付功能。直播测试以当前项目实现为准，主要验证房间状态、SRS 播放配置和直播评论流程。

### 2.3 测试方法

测试采用黑盒测试为主，结合接口返回结果和数据库状态进行验证。功能测试覆盖各模块的正常流程；异常测试覆盖未登录、参数为空、权限不足、资源不存在等情况；集成测试验证前端页面、后端接口、数据库和本地上传资源之间的数据传递。

### 2.4 测试通过准则

测试通过的标准是系统主要功能均按预期运行，关键页面能够正常访问，后端接口返回统一响应结构，数据库记录与页面展示一致，发现的问题已修复或在文档中说明。

记录预期结果和实际结果。

形成测试总结报告。

### 2.6 环境要求

测试环境包括必要的硬件、通信和系统软件。具体要求如下：

服务器：至少 2 核 CPU，4GB 内存，20GB 以上存储空间。

操作系统：Windows 10/11 或 Windows Server，也可部署于主流 Linux 发行版。

数据库：MySQL 8.0。

后端运行环境：JDK 25，Spring Boot 4.1.0-SNAPSHOT，MyBatis-Plus，Spring Security。

前端运行环境：Node.js 20.19+ 或 22.12+，Vue 3，Vite，Element Plus。

开发工具和测试工具：IntelliJ IDEA、VSCode、浏览器开发者工具、Apifox 或 Postman。

## 3 测试设计说明

### 3.1 目的

通过详细的测试设计，明确测试方法和要测试的特征，确保系统每个主要功能模块都经过充分验证。

### 3.2 详细说明

#### 3.2.1 测试设计说明标识符

测试设计编号：Doinb2026-TD-001

#### 3.2.2 要测试的特征

用户与权限管理功能：包括注册、登录、退出、个人资料编辑、头像上传和管理员权限识别。

视频播放功能：包括视频列表、视频详情、播放地址加载、播放历史保存和历史列表展示。

视频发布与编辑功能：包括视频上传、封面上传、待审核状态、编辑保存、可见性切换和删除。

评论与互动功能：包括发表评论、评论列表、视频赞踩、评论赞踩和分享链接复制。

关注订阅功能：包括关注、取消关注、关注状态显示和订阅动态聚合展示。

搜索功能：包括关键词查询视频、直播和用户，验证空结果展示。

消息功能：包括通知生成、通知已读、私信房间创建和消息发送。

直播功能：包括创建直播间、开播、停播、公开直播列表和直播间评论。

管理员功能：包括待审列表、审核通过、驳回为仅自己可见、举报复审和管理员删除。

#### 3.2.3 方法细化

功能测试：设计具体测试用例，验证页面操作和接口响应是否符合需求。

接口测试：直接请求后端接口，验证参数、鉴权和响应结构。

数据库测试：检查用户、视频、评论、关注、消息、直播间等数据表是否正确写入或更新。

异常测试：模拟未登录、权限不足、重复提交、空输入、资源不存在等情况。

回归测试：对修复后的功能重新执行相关用例，确认问题不再出现。

#### 3.2.4 特征通过准则

功能测试：所有核心测试用例通过，页面和接口结果一致。

接口测试：接口返回 `code=200` 或明确错误提示，异常不导致服务崩溃。

数据库测试：业务数据写入准确，主外键关系和状态字段符合设计。

异常测试：系统给出清晰提示，前端页面不出现不可恢复错误。
