# 01_source 代码 / 仓库清单

任务书允许交「代码或仓库清单」。完整可运行代码在 Git 仓库，不在本文件夹里再复制一份。

## 仓库

- GitHub：https://github.com/Lalalala-yeye/video_web_work
- 默认分支：`main`
- 克隆后按根目录 `README.md` 用 `.\scripts\k8s-up.ps1` 部署
