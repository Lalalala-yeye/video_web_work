# doinb 视频平台 - UI 设计系统

> 完整的视频平台 UI 原型，采用 Element Plus 风格设计

## 📋 项目概述

这是一个为中文视频网站「doinb」设计的完整 UI 基础模板，包含了从登录注册到视频播放、直播互动等所有核心功能页面。

**设计规格**：
- Desktop 1440px 宽度（内容区最大 1280px）
- Element Plus 风格设计系统
- 简体中文文案
- 所有页面可交互预览

## 🎨 设计系统

### 颜色规范

**主题色**
- 主色：`#409EFF` - Element Plus 蓝色
- 成功：`#67C23A`
- 警告：`#E6A23C`
- 错误/危险：`#F56C6C`
- 信息：`#909399`

**文字颜色**
- 主要文字：`#303133`
- 常规文字：`#606266`
- 次要文字：`#909399`
- 占位文字：`#C0C4CC`

**边框颜色**
- 基础边框：`#DCDFE6`
- 浅色边框：`#E4E7ED`
- 更浅边框：`#EBEEF5`

**背景颜色**
- 页面背景：`#F5F7FA`
- 卡片背景：`#FFFFFF`
- 填充色：`#F0F2F5`

### 字体规范

- H1 标题：24px / Medium (1.5rem / 500)
- H2 标题：20px / Medium (1.25rem / 500)
- H3 标题：18px / Medium (1.125rem / 500)
- 正文：16px / Normal (1rem / 400)
- 辅助说明：14px / Normal (0.875rem / 400)

### 圆角规范

- 小圆角：4px (0.25rem)
- 中圆角：6px (0.375rem)
- 大圆角：8px (0.5rem)

### 间距系统

采用 8px 栅格系统：8px, 16px, 24px, 32px, 48px

## 🎯 核心组件说明

### TopNavigation（全局顶栏）
- 高度：56px
- 包含：Logo、导航菜单、搜索框、用户信息
- 支持已登录/未登录两种状态

### VideoCard（视频卡片）
- 封面比例：16:9
- 包含：封面、标题、作者信息、播放次数、发布时间
- 支持悬停效果和播放按钮

### LiveCard（直播卡片）
- 封面比例：16:9
- 包含：封面、"直播中"标签、标题、主播信息、观看人数
- 红色"直播中"标签带动画效果

### CommentItem（评论项）
- 包含：用户头像、昵称、评论内容、点赞数、时间
- 支持嵌套回复展示

## 🖥️ 页面详细说明

### 1. Home - 视频首页
- 4列视频卡片网格布局
- 分页导航
- 响应式设计（移动端自动调整列数）

### 2. VideoDetail - 视频播放页
- 左侧：16:9 播放器 + 视频信息 + 评论区
- 右侧：推荐视频列表
- 包含播放控制、订阅按钮、评论输入

### 3. LiveList - 直播列表页
- 4列直播卡片网格
- 分类标签筛选
- 区分"直播中"和"离线"状态

### 4. LiveRoom - 直播间
- 左侧：直播画面（16:9）
- 右侧：聊天互动区（600px 高度）
- 实时消息滚动、礼物打赏按钮

### 5. Subscribe - 订阅动态
- 视频+直播混合 Feed 流
- 时间标记分组
- 筛选标签

### 6. Search - 搜索结果
- Tab 切换：视频/直播/用户
- 结果列表展示
- 支持空状态

### 7. Upload - 视频上传
- 拖拽上传区域
- 封面图上传
- 表单信息填写
- 上传进度条

### 8. Profile - 个人中心
- 用户信息展示
- Tab 切换：播放历史/收藏/订阅
- 统计数据（关注/粉丝/获赞）

### 9. DesignSystem - 设计规范
- 颜色系统展示
- 字体规范展示
- 组件库展示
- 所有基础组件的各种状态

### 10. EmptyState - 空状态
- 无视频、搜索无结果、未登录等各种空状态
- 配套操作按钮

## 📝 技术栈

- **框架**：React 18.3.1
- **样式**：Tailwind CSS v4
- **路由**：React Router 7
- **图标**：Lucide React
- **构建工具**：Vite 6

## 🎨 Element Plus 风格特点

1. **简洁明快**：清晰的视觉层次，简洁的交互反馈
2. **圆角设计**：4-8px 圆角，柔和友好
3. **蓝色主题**：#409EFF 作为品牌主色
4. **卡片布局**：白色卡片 + 浅灰背景的经典组合
5. **清晰表单**：明确的输入状态和错误提示

## 📐 后续开发建议

将此原型迁移到 Vue 3 + Element Plus 时：

1. **组件映射**：
   - Button → `<el-button>`
   - Input → `<el-input>`
   - Card → `<el-card>`
   - Tag → `<el-tag>`
   - Avatar → `<el-avatar>`
   - Empty → `<el-empty>`

2. **保持设计规范**：
   - 使用相同的颜色变量
   - 保持相同的间距系统
   - 复用相同的圆角规范

3. **响应式布局**：
   - 使用 Element Plus 的栅格系统 `<el-row>` / `<el-col>`
   - 保持 1280px 最大内容宽度
