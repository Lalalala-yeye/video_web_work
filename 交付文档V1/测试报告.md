# 测试报告

## 1 引言

### 1.1 目标

本测试报告旨在描述对 “doinb 视频播放与内容服务平台” 系统的测试活动，包括测试范围、测试方法、测试环境、测试用例和测试结果，确保系统在提交前经过较完整的功能验证，达到课程项目预期的功能和稳定性要求。

### 1.2 背景

“doinb 视频播放与内容服务平台” 是一个基于 Spring Boot 后端与 Vue 3 前端的视频内容网站，提供用户注册登录、视频浏览播放、视频上传与编辑、评论互动、关注订阅、搜索、通知私信、直播房间管理与管理员审核等功能。

### 1.3 范围

本测试报告适用于系统主要模块的 **接口模块测试**（Postman/Apifox）及必要的页面流程验证。模块包括：用户与权限、视频、评论、赞踩、关注订阅、搜索、通知私信、直播、管理员审核。

### 1.4 引用文件

- “doinb 视频播放与内容服务平台” 软件概要设计说明书
- “doinb 视频播放与内容服务平台” 软件详细设计说明书

### 2.3 测试方法

- **主要方式**：Postman 发送 HTTP 请求（URL + 输入 + Header），对比 `{ code, message, data }` 与预期。
- **辅助方式**：必要时在浏览器验证页面展示与接口结果一致。
- **异常测试**：未登录、错误参数、资源不存在、权限不足。

### 2.4 测试通过准则

- 成功用例：`code=200`，`data` 内容符合业务含义。
- 失败用例：返回明确错误 `code` 与 `message`，服务不崩溃。
- 统一响应结构：`{ "code": number, "message": string, "data": any }`。

   - `TOKEN_B`：用户 B 登录响应 `data.token`

5. 需登录接口在 Postman **Headers** 里添加（Key 必须是 `Authorization`，不要写成 `token`）：
   - Key：`Authorization`
   - Value：`Bearer <粘贴登录返回的 token>`（`Bearer` 后有一个空格）
